# Khaerul Istafa — Portfolio Website

Website portofolio statis menggunakan HTML, CSS, dan JavaScript vanilla.

## Menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser, atau gunakan extension Live Server di VS Code.
3. Untuk publikasi, unggah isi folder ke hosting statis seperti GitHub Pages, Netlify, atau Vercel.

## File
- `index.html` — struktur dan konten
- `style.css` — desain responsif, warna, layout, dan animasi
- `script.js` — menu mobile, filter proyek, reveal animation, navigasi aktif, dan tombol kembali ke atas

## Sebelum dipublikasikan
- Ganti URL LinkedIn dan GitHub dummy pada `index.html` dengan profil Anda yang benar.
- Tambahkan tautan proyek publik jika tersedia. Hindari memuat kode, screenshot, atau data internal perusahaan.
- Pastikan email dan nomor kontak yang ingin ditampilkan memang aman untuk dipublikasikan.
- Angka pengalaman dan proyek di halaman merupakan ringkasan/estimasi dari CV; sesuaikan bila ingin angka yang lebih presisi.
- Situs menggunakan Google Fonts; jika font tidak dapat diakses, fallback font tetap tersedia.
